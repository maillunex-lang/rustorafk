## Verification, compatibility and risks
Connected GitHub README.md and LICENSE inspected for all six referenced repositories: all MIT. Godot 4.4+ addon compatible in principle with newer Godot, but no Godot 4.7.2 or Android runtime tests were done. All Godot repos are UI/editor patterns, not Go/PostgreSQL authority. A distinct open-source Go percentile reward settlement library suitable for direct integration was not verified, so propose custom BUILD rather than pretending a drop-in exists. Potential design ambiguities requiring later approval: whether 100% entry after the first three is redundant, repeat counter reset scope, percentile boundary/ties for small populations, and whether every-25-floor enhanced reward replaces or adds to the normal five-floor reward. No code, dependencies, integrations, tests, server changes or APK builds.
