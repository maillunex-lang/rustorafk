# GitHub research and adoption policy

After each approved GDD stage:
1. Search GitHub for matching projects, plugins, templates and tooling.
2. Inspect actual repository, maintenance, engine version, Android support, dependencies and license.
3. Classify each candidate as ADOPT, ADAPT, REFERENCE or REJECT, with technical and legal risks.
4. Present a recommendation to owner; do not import or implement before approval.
5. After approval, log repository URL, revision/tag, license, attribution, modifications, tests and decision in the stage research file.
6. Update ROADMAP.md and GDD_DECISIONS.md in main after owner-approved decisions.

Never assume that a public GitHub repository permits commercial use when a license is absent. Prefer MIT, BSD or Apache-2.0 where appropriate, subject to license review. Track art licenses separately from code licenses.
