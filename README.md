# RuStore AFK

Commercial mobile online 3D Idle RPG project for RuStore.

## Status
- Genre direction: 3D Idle RPG, asynchronous online arena, base development.
- GDD-01: awaiting owner's selections.
- No third-party code or assets approved for integration.

## Approval workflow
1. Present GDD choices and recommendations.
2. Owner approves choices.
3. Research relevant GitHub projects, licenses and Android/Godot compatibility.
4. Present adopt/adapt/reject recommendations.
5. Owner approves integrations.
6. Commit approved GDD decisions and update ROADMAP.md.

No external repository code is integrated without owner approval.
